# A11y Fixer

Локальное расширение VS Code для Vue 3 и Vite. Оно само поднимает dev-сервер, находит нарушения доступности и делит их на быстрые, ручные и неоднозначные. Быстрая правка записывается только после нажатия кнопки.

## Как попробовать

В корне репозитория:

```bash
npm install
npm --prefix demo install
npm run check
```

`npm run check` компилирует расширение и прогоняет демо без окна VS Code.

В Cursor откройте эту папку, затем Run and Debug и конфигурацию «Запустить A11y Fixer». Откроется новое окно с папкой `demo`. На панели слева выберите A11y Fixer и нажмите «Проверить».

На вкладке быстрых правок можно исправить одну проблему, все сразу, перепроверить, создать `a11y-fixer-report.md` и отменить последнюю запись. «Показать в коде» открывает файл и выделяет найденный фрагмент. На ручной вкладке расширения файл не меняет.

Нужен установленный Chrome или Chromium. Если браузер лежит не в обычном месте, задайте `CHROME_PATH`.
